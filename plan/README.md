# CrowdFlow — Planning Documents

Predictive crowd management for Grand Prix circuits. Participating phones become anonymous
crowd nodes; the system predicts bottlenecks before they form, simulates interventions, and
reroutes people to prevent them.

> We don't just detect crowds. We predict where they will get stuck and move them before they do.

## Design

Direction is not settled, but it is anchored: see
[`design-references.md`](./design-references.md), which surveys the established F1 live-timing
dashboards. Their conventions are a far better starting point than anything invented, because
race staff and spectators already read them fluently.

**Nothing in `../mockups/` is a reference** &mdash; throwaway explorations, direction rejected.

## Circuits

All 23 rounds of 2026 are indexed in [`../circuits/index.yaml`](../circuits/index.yaml),
generated by joining the Jolpica calendar to the f1-circuits geometry dataset. Each entry
carries its own coordinate frame derived from its bbox. **Silverstone is the seed circuit**;
the rest follow one at a time.

## Decisions already locked

| | Decision |
|---|---|
| D1 | npm/TypeScript monorepo; contracts authored once in TypeScript, JSON Schema generated deterministically |
| D2 | CLI-first over a pure core library; API and CLI are equal adapters |
| D3 | React Native + Expo app; mesh is a native Kotlin module at the `MeshNetwork` seam |
| D4 | Each circuit is a data pack (engines) + `SKILL.md` (agent) |
| D5 | Track crossings are time-gated, so routing is time-dependent |
| D6 | The venue structure is **imported** from OSM + the official venue map; traces **refine** it, they don't create it |
| D7 | **Any connected node is a gateway** — no fixed uplink infrastructure |
| D8 | The surfaces are **deliberately asymmetric** — app simple and beautiful, console dense and organised |

## Critical path

```
P platform → A circuit → B simulator → C state → D prediction
          → E/F intervention + routing → J3 tick loop → M dashboard → N metrics
```

**M5 is the demo** and needs zero phones. Mobile mesh (M6), agent (M7), and circuit swap (M8)
are differentiators layered on top.
