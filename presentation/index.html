The system does not just detect crowds. It tests what to do next.

CrowdFlow fuses observations into state, predicts risk, simulates several diversion levels, routes the chosen intervention through a mandatory safety review, and then watches whether it worked. That feedback loop is the product.

This is not a slideware metric. Both arms run the real deterministic simulator with the same seed. The intervention reduced exposure and queues without increasing mean walk time. That gives us a falsifiable baseline for every pilot.

CrowdFlow computes the forecast and route deterministically. It evaluates multiple diversion fractions and every command expires after five minutes. Most importantly, safety is not a disclaimer: it is a mandatory code path with veto power.
